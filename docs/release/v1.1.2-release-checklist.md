## 四项用户修复

- [x] 编辑器右下角保存按钮执行有意义的保存动作并给出明确成功/失败反馈；返回前仍强制 flush 串行自动保存。
- [x] 提醒选择器支持 `00` 至 `59` 的每一分钟，禁止过去时间，并保留创建、修改、删除、权限恢复、暂停、过期与稍后提醒链路；Android 授权时使用 `exactAllowWhileIdle`，拒绝时保留时间并以 `inexactAllowWhileIdle` 回退且明示可能延迟；已不 pending 的请求采用 2 分钟收尾宽限，仍 pending 的请求保守保留 75 分钟且不受后续权限切换误伤。
- [ ] Android/iOS 到点提醒在用户与系统设置均开启时实际发声和振动；Android API 24/25 使用显式振动节奏，已被系统静音的既有频道必须被识别并提供设置入口，不暗中轮换频道 ID。
- [x] 过往中每个事件只占一行，内容在前、时间与日期在后；同日事件只换行，不同日期之间只空一行。
- [x] 原生启动阶段仅显示暖纸色；Android 12+ 使用显式透明 drawable，不回退 launcher icon，暗色模式不出现黑闪。
- [x] Flutter 完整水彩插画、“当归”、印章、隐私文案、真实加载状态从插画首个可见帧起至少展示 `1200 ms`；初始化失败继续提供重试。
