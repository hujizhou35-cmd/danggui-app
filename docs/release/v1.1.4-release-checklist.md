## 代码与兼容

- [ ] Android 新闹钟由 AlarmManager 直接进入响铃服务，旧 Receiver PendingIntent 保留一版兼容与清理。
- [ ] Android 服务校验 reminder/revision/session，唤醒锁、声音、震动与响铃均有明确超时。
- [ ] Android 与 iOS 均实现先确认新修订后退役旧修订，重复操作不得影响较新修订。
- [ ] 跨平台统一 15 分钟迟到窗口；超时记录 `missed`，打开 App 不补响。
- [ ] `listAlarmSnapshots()`、交付等级、revision/session 操作与统一诊断合同在 Android/iOS/Dart 对称。
- [ ] iOS AlarmKit actor、revision UUID、持久两阶段事务、容量延迟与排除 iCloud 备份的本地镜像完成。
- [ ] 应用只主动请求可请求权限；受保护特殊权限仅打开系统页并返回复检。
- [ ] 快速滚动条、SnackBar 时长、数据库 schema 与现有本地数据保持无回归。
