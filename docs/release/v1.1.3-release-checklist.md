## 用户升级

- [x] 有声提醒走 Android 原生闹钟通道：`setAlarmClock`、闹钟音频流、循环振动、媒体播放前台服务、锁屏全屏界面与通知回退。
- [x] Android 提供停止和 10/30/60 分钟稍后提醒；重启、系统时间/时区变化、应用升级与精确闹钟授权变化后恢复未来闹钟。
- [x] 应用主动发起通知、精确闹钟、全屏提醒和 iOS AlarmKit 授权；为主要国产/OEM 机型提供自启动设置入口，同时保留用户确认，不申请 Critical Alerts 或勿扰政策访问。
- [x] iOS 26+ 使用 AlarmKit，iOS 15–25 使用 Time Sensitive 本地通知回退，不申请 Critical Alerts。
- [x] 长事项详情、事项列表、笔记编辑/列表、过往编辑、设置、帮助正文和最近删除增加可拖动快速滚动条。
- [x] SnackBar 统一为有限时长，新的反馈先清理旧反馈；保存 1.5 秒、信息/校验 3 秒、撤销 4 秒、权限/错误 5 秒。

## 版本与兼容

- [x] `pubspec.yaml` 与运行时共享常量为 `1.1.3+4`；Android/iOS 构建值继续从 Flutter 版本源派生。
- [x] 不新增数据库 schema；升级时既有未来有声提醒由启动修复路径迁移至原生闹钟，提醒 ID 与修订号保持稳定。
