## Спокойное приложение с локальным хранением

Danggui объединяет задачи, единый редактируемый журнал завершённых дел и отдельные заметки. Приложение не требует учётной записи, не загружает данные, не использует ИИ, рекламу, аналитику или профилирование.

- Задачи с датой, планом, списком и одним локальным напоминанием, время которого видно на карточке.
- Завершённые задачи добавляются в единый редактируемый документ истории.
- Заметки с одноуровневыми папками, закреплением, списками и преобразованием в задачу.
- SQLite-транзакции, миграции, проверка целостности, резервные копии `.dgbak` с необязательным шифрованием, слияние/замена при восстановлении и читаемый экспорт Markdown + JSON.
- Подробная автономная справка и интерфейс на упрощённом китайском, английском, японском и русском языках; системный и ручной выбор.

## Распространение

| Платформа | Поставка |
| --- | --- |
| Android | Подписанные универсальные и раздельные APK, а также AAB в [GitHub Releases](https://github.com/hujizhou35-cmd/danggui-app/releases) после прохождения всех критериев выпуска |
| iOS | Полный исходный код, проект Xcode и подтверждение сборки `Runner.app` без подписи; в v1.0.0 нет IPA/TestFlight |

Официальный выпуск Android включает `SHA256SUMS` и SHA-256-отпечаток сертификата подписи. Большинству пользователей следует выбрать APK с `universal-release.apk` в имени; раздельные APK предназначены для тех, кто знает ABI устройства. См. [руководство по сборке и поставке](../architecture/platform-delivery.md) и [список проверок v1.0.0](../release/v1.0.0-release-checklist.md).

Приложение не требует учётной записи и не содержит рекламы, аналитики, Firebase, ИИ или SDK отслеживания. Данные пользователя остаются в песочнице приложения и выбранных пользователем локальных копиях; Android не запрашивает разрешение `INTERNET`.
