## Спокойное приложение с локальным хранением

Danggui объединяет задачи, единый редактируемый журнал завершённых дел и отдельные заметки. Приложение не требует учётной записи, не загружает данные, не использует ИИ, рекламу, аналитику или профилирование.

- Задачи с датой, планом, списком и одним локальным напоминанием, время которого видно на карточке.
- Завершённые задачи добавляются в единый редактируемый документ истории.
- Заметки с одноуровневыми папками, закреплением, списками и преобразованием в задачу.
- SQLite-транзакции, миграции, проверка целостности, резервные копии `.dgbak` с необязательным шифрованием, слияние/замена при восстановлении и читаемый экспорт Markdown + JSON.
- Подробная автономная справка и интерфейс на упрощённом китайском, английском, японском и русском языках; системный и ручной выбор.
- В v1.1.2 напоминания задаются с точностью до минуты, сохранение даёт явную обратную связь, а каждое событие истории занимает одну строку. Нативный этап показывает только бумажный фон, после чего единственная полная Flutter-композиция запуска остаётся на экране не менее 1,2 секунды.

## Распространение

| Платформа | Поставка |
| --- | --- |
| Android | Универсальный и раздельные APK, а также AAB с официальной подписью на странице [v1.1.2 Pre-release](https://github.com/hujizhou35-cmd/danggui-app/releases/tag/v1.1.2) |
| iOS | Детерминированный `danggui-ios-source-v1.1.2.zip`, проект Xcode и подтверждение сборки `Runner.app` без подписи; IPA/TestFlight не предоставляются |

Большинству пользователей Android следует скачать `danggui-android-universal-release.apk`; раздельные APK предназначены для тех, кто знает ABI устройства, а AAB — для магазинов приложений или управляемого распространения. К Pre-release также приложены `SHA256SUMS` и SHA-256-отпечаток сертификата подписи; перед установкой следует проверить оба. См. [руководство по сборке и поставке](../architecture/platform-delivery.md), [инструкцию по сборке iOS](../architecture/ios-source-build.md) и [список проверок v1.1.2](../release/v1.1.2-release-checklist.md).

## Статус приёмочных испытаний Pre-release

Автоматические приёмочные испытания выполнили обновление поверх установки с той же версией и той же подписью на Android API 24 и API 36. Проверены 37 утверждений о сохранности данных в шести областях, `quick_check` SQLite и целостность внешних ключей, планирование через AlarmManager, настоящее системное уведомление и реальный процесс выдачи разрешения на уведомления в API 36.

Ещё не завершены испытания на физических Android-устройствах разных производителей, доставка уведомлений на экран блокировки, звук, вибрация, snooze и финальная приёмка обновления поверх опубликованного v1.1.0. Поэтому v1.1.2 остаётся Pre-release, а не стабильным выпуском.
