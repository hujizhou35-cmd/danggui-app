# F01–F28 功能树与行为合同

本页定义可测试的产品语义。`P0` 表示错误会造成漏提醒、错误提醒、数据丢失、不可恢复或隐私破坏；`P1` 表示核心工作流失效；`P2` 表示体验或发布保证。合同不因参考项目采用不同架构而改变。

## P0：平台、提醒、数据与恢复链

### F01 启动、场景与进程恢复（P0）

**合同**：冷启动、通知启动、普通启动、前后台切换只初始化一次；所有持久化状态先于派生设备态恢复。进入前台或系统时间显著变化后，应用必须对账系统提醒、outbox 与逻辑提醒。进入后台前，已确认的编辑和关键状态必须落盘。

- 正常：普通冷启动、场景重连、后台恢复、通知点击均落到同一幂等初始化流程。
- 异常：重复生命周期回调、数据库暂不可用、通知载荷无效、目标已删除时不得崩溃或重复排期。
- 跨模块：启动恢复后依次验证数据库 → outbox → 系统快照 → 导航；编辑器后台 flush 与备份/导出不得互相覆盖。
- 必测：冷启动动作、重复 `resumed`、场景断开/重连、时间/时区变化、恢复中进程终止。

### F03 提醒生命周期（P0）

**合同**：提醒由 reminder ID、单调递增 revision、不可复用 session/platform ID 唯一标识。创建、替换、取消、Stop、10/30/60 分钟 Snooze 均幂等；旧 revision/session 的迟到动作绝不能修改当前提醒。编辑采用“先建立并验证新 revision，再退休旧 revision”。

- 正常：未来提醒最终只保留最新 revision；Stop 结束本 session；Snooze 生成新 revision/session 并退休前驱。
- 异常：平台容量不足、授权撤销、系统快照缺失、重复回调、部分持久化失败时不得虚构投递或丢掉重试依据。
- 跨模块：完成/删除事项退休提醒；恢复事项重建未来提醒；备份恢复不复用来源设备 platform ID。
- 必测：每个持久化边界故障注入；旧动作重放；连续编辑；60/64 边界；20 轮短周期 Simulator；15 分钟窗口两侧。

### F04 权限与能力等级（P0）

**合同**：应用主动调用系统授权 API；`alarm-grade / time-sensitive-best-effort / ordinary / unavailable` 必须反映当前授权和平台实际设置。不能把打开设置页说成授权成功，不能把可调度等同于有声音。

- 正常：首次请求、拒绝、系统设置恢复后界面和调度策略同步更新。
- 异常：通知总体授权、Time Sensitive、alert、sound、AlarmKit 任一被撤销时，能力不得保持虚高。
- 跨模块：能力变化触发对账和可解释诊断，但不自动清除逻辑提醒。
- 必测：每种授权组合、设置往返、并发请求、API unavailable、回调错误。

### F09 最近删除与永久删除（P0）

**合同**：删除先进入最近删除，默认 30 天；恢复和永久删除各自事务化且可重试。恢复任务/笔记时重建搜索和未来提醒，过期提醒只记 `missed`，不得补响。

- 正常：删除、恢复、到期清理、永久删除保持引用完整。
- 异常：条目已处理、内容损坏、清理中进程终止、恢复与永久删除并发时不产生半恢复对象。
- 跨模块：搜索、过往、提醒、导出和备份只观察到提交前或提交后的完整状态。
- 必测：30 天边界；恢复幂等；提醒 revision 增长；清理各事务边界故障。

### F10 备份创建（P0）

**合同**：备份来自同一 SQLite 一致性快照；manifest、数据库和附件均被哈希覆盖。写入使用私有临时文件、完整校验、原子发布；失败不得留下被误认作成功的文件。设备派生态、平台 ID 和密钥不得导出。

- 正常：手动/自动 `.dgbak` 可 inspect、可往返、重复创建不改变业务语义。
- 异常：磁盘满、WAL checkpoint 失败、压缩/哈希/改名失败、分享取消时保留良好数据库并清理明文临时文件。
- 跨模块：自动保存、搜索更新和提醒 outbox 与备份并发时快照仍自洽。
- 必测：每个写入阶段前后故障、超大库、低空间、Unicode、进程终止、文件保护属性。

### F11 加密、口令与 Keychain（P0）

**合同**：加密备份使用随机 salt/nonce、内存困难 KDF 和带认证加密；错误口令、篡改密文/标签一律失败关闭。设备密钥不可同步，采用符合后台需要的最小 Keychain 可访问性；日志和临时文件不得含口令/密钥/明文。

- 正常：正确口令往返；每次加密产生不同 salt/nonce；设备密钥可在首次解锁后后台读取。
- 异常：设备重启尚未首次解锁、Keychain 缺项/锁定/重复项、KDF 中断、认证失败不得降级为明文。
- 跨模块：恢复前只 inspect 元数据；密钥不可随备份或 iCloud 同步迁移。
- 必测：固定向量、随机往返、篡改每个字段、缺失密钥、错误可访问性、清理扫描。

### F12 inspect、replace 与 merge 恢复（P0）

**合同**：所有外部输入先在隔离目录解包并进行路径、大小、哈希、格式、schema 和 SQLite 完整性验证。replace 前建立已验证安全副本，原子交换；merge 映射新 ID，不复用平台 ID，重复执行无重复数据。失败不得覆盖良好数据库。

- 正常：兼容旧格式 inspect；replace/merge 后重建搜索、outbox 和未来提醒。
- 异常：ZIP 穿越/符号链接、截断、CRC/认证标签错误、未来 schema、磁盘满、交换中断均失败关闭并可回滚。
- 跨模块：旧系统提醒先退休，来源设备派生态被剥离，过期提醒记 missed 不补响。
- 必测：恶意 ZIP 语料；旧版夹具；两次 merge；每个 swap 边界；恢复后提醒和搜索对账。

### F15 时间、时区与本地日期语义（P0）

**合同**：绝对触发点持久化为 UTC，同时保存足以重建用户意图的本地日期组件和 IANA 时区标识。夏令时缺失/重复时刻采用明确策略；系统时区或时钟变化不会静默移动既定意图。

- 正常：同一时区重启、跨时区旅行、语言切换不改变语义。
- 异常：DST spring-forward/fall-back、手动改时钟、时区规则更新、设备时间回拨时不得重复或补响过期提醒。
- 跨模块：编辑、Snooze、备份/恢复、导出均保持同一 UTC 与本地意图映射。
- 必测：固定时钟、IANA 区域、DST 边界、15 分钟边界、跨区恢复。

### F16 SQLite 完整性、事务与并发（P0）

**合同**：外键、唯一约束和 revision 在数据库层强制；跨表业务操作单事务提交。WAL、checkpoint、quick/integrity check 的失败必须可诊断，且应用不在未知完整性上继续破坏性写入。

- 正常：并发读写、备份和 outbox 消费保持一致。
- 异常：磁盘满、I/O 错、WAL/SHM 丢失、损坏页、进程终止、重复唯一键时保持最后已知良好副本。
- 跨模块：数据库恢复完成前不得启动提醒对账、清理或搜索重建。
- 必测：事务四边界、SQLite fault 注入、损坏夹具、只读文件系统、快速检查失败。

### F17 outbox 与派生设备态（P0）

**合同**：业务事务只写逻辑状态和 durable outbox；平台调用可重试且由 `kind:id:revision` 去重。平台快照和诊断属于可重建派生态，不得反向覆盖更新的逻辑 revision。

- 正常：outbox drain 后最终一致，重复 drain 无副作用。
- 异常：平台调用成功但确认未写、确认写前崩溃、旧 job、损坏镜像、容量不足时保留可解释重试状态。
- 跨模块：删除、恢复、replace/merge 和授权恢复均经同一 outbox 路径。
- 必测：每个边界中断、乱序/重复 job、部分损坏镜像、系统快照差异。

### F18 schema 迁移与版本拒绝（P0）

**合同**：迁移顺序固定、每步幂等或事务化，支持从每个已发布 schema 升级；中断后可安全重试。高于应用支持范围的未来 schema 明确拒绝，不能尝试降级打开。

- 正常：v1.1.3/v1.1.4 数据夹具升级后业务与 Unicode 不变。
- 异常：每一步提交前后中断、重复执行、缺列、部分索引、磁盘满时保持可恢复。
- 跨模块：迁移完成后才重建搜索/outbox；备份 manifest 版本与 SQLite schema 双重核对。
- 必测：逐版本真实夹具、未来版本、crash matrix、rollback journal/WAL 两种模式。

### F19 Flutter/Swift 边界与 AlarmKit 适配（P0）

**合同**：MethodChannel 字段兼容旧版，只做增量扩展；所有入参严格验证，错误映射稳定，FlutterResult 仅调用一次。Swift actor 串行化同一提醒的调度和动作，所有版本可用性分支可测试。

- 正常：能力、调度、取消、Stop/Snooze、快照和诊断序列化往返无损。
- 异常：缺字段、错误类型、溢出 epoch、未知 enum、API 抛错、并发调用不得崩溃或双回调。
- 跨模块：普通通知与 AlarmKit 使用相同 reminder/revision/session 合同。
- 必测：channel fuzz、错误码快照、actor 并发、iOS 18.5 回退、iOS 26.5 AlarmKit。

### F20 iOS 文件、沙盒、备份排除与保护（P0）

**合同**：数据库、镜像、诊断、备份 staging 位于合适的 Application Support/Caches/tmp；派生设备态排除 iCloud。敏感持久文件设置与后台读取需求匹配的文件保护；临时明文用后删除。原子替换保留所需元数据。

- 正常：首次创建、目录迁移、重启后属性仍正确。
- 异常：属性设置失败、文件锁定、空间不足、旧路径迁移中断时不得删掉唯一良好副本。
- 跨模块：数据库、备份、Keychain 可访问性在首次解锁前后行为一致。
- 必测：URL resource values、文件保护属性、排除备份、旧路径迁移失败、tmp 扫描。

### F21 隐私、诊断与日志（P0）

**合同**：诊断最多 200 条，只记录状态码、匿名 ID、revision/session 和时间；不得记录事项/笔记正文、口令、密钥、完整外部路径。事件必须如实：没有平台证据不能记 `delivered/audio/vibration`。

- 正常：registered、delivered、foreground/systemAlert、audio、vibration、missed、stopped、snoozed、error 可追踪并可清理。
- 异常：平台错误文本、损坏数据、导出失败不泄漏敏感参数；日志写失败不影响业务事务。
- 跨模块：发布证据包仅收集允许字段，成功 CI 不上传用户数据。
- 必测：静态敏感词扫描、200/201 边界、错误注入、诊断真值测试。

## P1：核心业务工作流

### F02 事项

创建、编辑、稳定排序、完成、重新开启、删除和恢复必须以 revision/事务保持原子；并发旧编辑不能覆盖新值。完成/删除立即产生退休提醒 outbox。测试覆盖重复操作、排序冲突、大量数据和与提醒/过往/搜索的交错。

### F05 过往、anchors 与 parts

完成事项生成来源快照和可编辑过往，anchors/parts 保持稳定定位；合并/拆分/删除原子。测试覆盖 emoji、组合字符、多段长文、旧 revision、撤销与搜索/导出往返。

### F06 笔记与文件夹

笔记、文件夹、置顶、未分类、移动和笔记转事项不得孤立或重复内容。文件夹删除与编辑自动保存并发时遵守明确冲突策略；恢复重建搜索。

### F07 编辑器、自动保存与撤销重做

自动保存按文档串行且旧 revision 不覆盖新 revision；中文/日文输入法 composing range、光标、选择区和 undo/redo 在后台、返回和进程终止边界保持一致。分享/备份前 flush 只能等待已确认快照。

### F08 搜索

搜索索引是可重建派生态；事务提交后最终反映创建、编辑、删除、恢复和导入。中英日俄、大小写、emoji 和组合字符规范化可预测，损坏索引可安全重建。

### F13 可读导出与分享

Markdown/JSON/ZIP 使用 UTF-8、稳定顺序、安全路径和版本化 manifest；文件名碰撞不覆盖，取消分享不改变数据。测试覆盖恶意标题、Unicode、超长内容、磁盘满和逐字节可重复性。

### F14 设置

语言、字体、字号、密度、默认提醒与权限说明持久化且带乐观锁；冲突对用户可解释。默认提醒只影响新建或用户明确要求的事项，不静默重写既有提醒。

### F22 导航与系统入口

普通入口、通知点击和动作冷启动都安全解析；目标删除/无权限/载荷过期时降级到稳定页面并给出短时提示。重复系统回调不得多次执行业务动作。

### F25 性能与资源

大量事项、长文、搜索、备份/恢复不得阻塞主线程或产生无界内存/临时空间峰值。指标必须有固定数据集、设备/Simulator 配置和阈值；性能优化不得绕过事务或校验。

## P2：体验与发布保证

### F23 UI 基础

快速滚动条在长内容可见、可拖动且不遮挡正文；Snackbar/撤销提示有界时长且安全区正确；键盘、横竖屏和分屏不会遮挡关键操作。

### F24 无障碍与四语本地化

VoiceOver 顺序、标签/值/动作完整；交互目标至少 44×44 pt；最大 Dynamic Type、粗体、小屏与 iPad 不截断关键动作。中英日俄日期、复数和系统动作语义一致，组合字符往返无损。

### F26 依赖、许可证与供应链

Flutter/Dart/Xcode/Pods 和动态原生文件固定版本与 SHA-256；生产依赖有许可证台账、隐私用途和移除路径。GPL/AGPL/SSPL/无许可证来源只研究行为，不复制代码。

### F27 帮助、关于与诊断说明

关于页版本锁定为构建元数据；帮助明确普通通知、AlarmKit、声音/振动系统控制和真机未验证边界。诊断导出只含允许字段，四语一致。

### F28 CI、制品与发布保证

标签不可变且来自合并后的 `main`；APK、iOS 源码包、证据包和 `SHA256SUMS` 相互匹配。iOS 只有 unsigned build/Simulator 证据时不得提供 IPA 或宣称真机验收。失败上传 `.xcresult` 与最小日志，成功只保留摘要。

## 必须整体通过的跨模块场景

1. 连续修改提醒只留下最新 revision；完成/删除后旧系统提醒不得继续。
2. 恢复事项只重建未来提醒；超过 15 分钟的提醒只记 `missed`，打开 App 不补响。
3. Stop/Snooze、编辑和冷启动并发仍保持 revision/session 幂等。
4. 权限撤销/恢复后能力和界面真实，逻辑提醒不被静默删除。
5. replace/merge 后来源平台 ID 不复用，旧系统提醒退休，重复恢复不重复数据。
6. 时区、DST、语言切换不改变用户设定意图。
7. 磁盘不足、进程中断、损坏输入绝不能覆盖良好数据库。
8. 自动保存、导出、备份、返回和进程终止交错仍一致。
9. 四语、emoji、组合字符经过编辑、备份、恢复和导出保持不变。
