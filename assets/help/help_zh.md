# 当归操作指南

当归是一款本地优先的事项、过往与笔记应用。所有内容默认只保存在当前设备；应用不要求账号，也不会上传内容或调用 AI。

## 事项

### 快速新建

1. 打开“事项”，点击右上角的加号。
2. 输入事项名称；标题不能为空。
3. 日期是可选的。点击日期行选择日期，或保留“不设置日期”。
4. 点击“保存”立即加入列表；点击“更多设置”可继续填写计划、提醒、正文和清单。

### 编辑事项

1. 点击任一事项卡片进入详情。
2. 点击标题、日期、计划或正文即可修改。
3. 正文工具栏可插入普通段落、项目符号、编号和勾选项。
4. 离开编辑页前会提交最后一次自动保存；顶部返回键和系统返回键行为一致。

### 设置提醒

1. 在事项详情中点击“提醒”。
2. 选择提醒日期、小时和分钟；提醒日期可以早于事项日期。
3. 按需开启声音和振动，然后点击“确定”。
4. 首次使用时允许系统通知权限。如果拒绝，提醒仍会保存在事项中，但不会响铃，可稍后在系统设置中重新授权。
5. 关闭事项会暂停它的提醒；重新开启时，只有尚未过期的提醒会重新安排。过期提醒不会突然补发。

卡片会把提醒直接写在日期旁：同日提醒显示“8月25日（19:50 提醒）”；跨日提醒显示“8月25日（8月24日 19:50 提醒）”；没有事项日期时直接显示提醒日期和时间。

### 完成、加入过往或撤销

1. 点击事项卡片右侧开关，把事项置为“待归档”。可以同时关闭多条事项。
2. 点击“加入过往”，事项会按完成日期追加到“过往”长文档末尾。
3. 点击“删除”会移入“最近删除”，保留 30 天。
4. 如果误操作，使用底部提示条的“撤销”，或重新打开事项开关。

### 搜索与排序

- 点击顶部搜索按钮，可搜索标题、计划、正文和日期。
- 选择“手动排序”后长按卡片拖动；选择“按日期排序”后，未设置日期的事项排在有日期事项之后。

## 过往

“过往”是一篇连续生长的长文档，不是许多独立日记。加入过往的事项会在末尾形成日期、标题和正文内容，你仍可像编辑普通文档一样修改它。

### 编辑、撤销和恢复版本

- 点击任意文字直接编辑；支持段落、列表、编号和勾选项。
- 工具栏提供撤销和重做。
- 应用会在后台、离开编辑器和破坏性修改前保存版本快照。快照不等同于回收站，不会为每个段落单独建立“已删除”项目。

### 把文字转为事项

1. 长按并选择一段文字。
2. 在系统文字菜单中选择“转为事项”。
3. 只选一行时，该行成为标题；选择多行时，第一个非空行成为标题，其余文字成为正文。
4. 确认面板会先显示预填内容，你可补充日期后再创建。
5. 原文字始终保留，避免破坏长文档上下文。

### 搜索和导出

- 使用顶部搜索查找当前可见文字；选择结果会定位并高亮。
- 点击导出，可导出全部内容、指定日期范围或当前所选文字。
- 便携导出是 ZIP，同时包含可阅读 Markdown、结构化 JSON、Manifest 和校验和。完整 `.dgbak` 备份用于恢复，两者用途不同。

## 笔记

### 新建和编辑

1. 在“笔记”点击加号。
2. 输入标题和正文；空标题也允许保存。
3. 工具栏支持项目符号、编号、勾选项、撤销和重做。
4. 从更多菜单可把选中文字转成事项、导出笔记、置顶或删除。

长按笔记进入多选模式：可继续点选多篇，然后批量移入一级文件夹、导出 Markdown＋JSON ZIP 或移入最近删除。只选一篇时还可转为事项；原笔记不会被删除。

### 文件夹

- 点击文件夹栏旁的按钮新建文件夹。
- 当归只使用一级文件夹，避免复杂层级。
- 删除文件夹不会删除其中笔记；笔记会移动到“未分类”。
- 置顶笔记始终显示在普通笔记之前。

## 显示、语言和提醒默认值

1. 打开“设置”。
2. 在“显示”中选择跟随系统、简体中文、English、日本語或Русский，界面会立即切换，用户写的内容不会被翻译。
3. 可调整无衬线/衬线显示、字号和卡片密度。
4. 在“提醒”中设置新提醒默认使用的声音、振动和稍后提醒时长（10、30 或 60 分钟）。
5. 系统语言不受支持时，应用回退到简体中文。

## 备份、导出与恢复

### 创建备份

1. 开启“每日自动备份”后，应用会在启动或回到前台时检查，尽力每天在应用内部目录生成一份完整备份，并保留最近 30 份。
2. 操作系统不保证应用完全关闭时按点运行；错过的当日备份会在下次启动或回到前台时补做。
3. 内部备份可能随卸载或清除应用数据而丢失。点击“立即创建备份”会先生成并校验 `.dgbak`，再打开系统分享面板，你可主动另存到“文件”、电脑或其他本地位置。
4. 备份先写入临时文件，重新读取并校验通过后才标记成功；最后一份有效备份不会因为新备份失败而提前删除。
5. 可选开启备份加密。用于每日备份的密码只存在本机系统安全存储中，不会上传；忘记后无法恢复加密备份。
6. “导出全部数据”生成供阅读、迁移或主动提供给其他工具的 Markdown＋JSON ZIP，它不等同于可完整恢复的 `.dgbak`。

### 恢复备份

1. 点击“从备份恢复”，选择可信的 `.dgbak` 文件。
2. 应用先只读检查格式、版本、完整性和记录数量，并显示备份时间、Schema、加密状态、各类记录数与校验摘要；此时尚未改动当前数据。
3. 核对后选择“合并恢复”或“覆盖恢复”。覆盖会再次明确警告。
4. 在真正修改数据前，会先创建当前数据的恢复前安全备份。
5. “覆盖恢复”用备份替换当前内容；“合并恢复”保留当前内容，并把冲突项目复制为新项目，不静默覆盖。
6. 恢复后的未来提醒需要重新登记；已过期提醒不会补发。

### 最近删除

- 删除的事项和笔记保留 30 天，可在“设置 > 最近删除”恢复或永久删除。
- 删除事项时会同时取消平台通知；恢复未来提醒时会重新安排。
- 过往中的普通文字不进入最近删除，请使用撤销、重做或版本快照。

## 隐私、权限与故障排查

- 当归不申请联网权限，不包含账号、广告、分析统计、崩溃上传或遥测。
- 通知权限只用于本地提醒；文件访问只在你主动导入、另存或分享时由系统面板授予。
- 若提醒未响：检查系统通知权限、省电限制、事项是否已关闭，以及提醒时间是否已经过去。
- 若备份失败：确认设备空间充足，再手动重试并另存一份。不要通过关闭安全校验或使用来源不明的文件绕过错误。
- 若启动自检失败：点击“重试”。仍无法打开时，先保留应用数据和最近备份，再提交问题报告；不要卸载应用，以免系统删除本地数据库。

## 分享与问题反馈

分享应用时优先使用项目发布页的已签名安装包，并核对 SHA-256。报告问题时请写明应用版本、Android/iOS 版本、复现步骤和预期结果；不要上传含私人内容的数据库或备份文件。
